# Humanizing Writing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bilingual skill that removes formulaic AI-writing patterns from everyday prose, technical documentation, and pull request descriptions without inventing facts or erasing the writer's voice.

**Architecture:** Keep routing, preservation rules, invocation modes, and the rewrite-audit-final loop in one concise `SKILL.md`. Put Chinese and English pattern catalogs in separate first-level reference files so agents load only the language they need. Integrate the skill into Devkit discovery and validate it with fresh-context control and skill-enabled samples.

**Tech Stack:** Markdown, YAML frontmatter, Codex skill scaffolding and validation scripts, Devkit shell validation, fresh-context subagent evaluations.

## Global Constraints

- Skill folder name is exactly `humanizing-writing`.
- Support Chinese and English.
- Route everyday writing, technical documentation, and PR descriptions separately.
- Preserve every source-backed fact, name, number, date, quotation, citation, URL, code block, frontmatter field, command, and identifier.
- Never claim to determine whether AI authored a text.
- Do not translate unless the user asks.
- Prefer author samples and explicit tone requests over generic style rules.
- Treat pattern clusters as evidence; never ban a word or punctuation mark based on one isolated occurrence.
- Keep references one level below `SKILL.md`.
- Do not add a keyword-scanning script in the first version.
- Base English guidance on `https://github.com/blader/humanizer/blob/main/SKILL.md` and `https://github.com/hardikpandya/stop-slop`, retaining both sources and their MIT-license attribution.
- Adopt Stop Slop's structural checks and qualitative dimensions, but convert blanket bans on adverbs, Wh- openers, em dashes, passive voice, and inanimate subjects into contextual signals.
